Independent hardware testing

Rome, Italy · measurements published in Italian and English

I measure hardware and publish what the instruments say, with the method stated and the raw logs kept available. One unit per product. No paid placements, no sponsorship of the result, no affiliate link that changes what a number means.

What gets measured

ThermalSustained load, then the soak: does performance hold once the enclosure is hot.
PowerDraw at the wall, not the figure on the box.
NoiseMeasured from a fixed distance, same room, same conditions.
Sustained behaviourHour one against hour four, because that is where specifications stop predicting.

How it is done

  • One protocol, applied identically across every unit tested, so results compare.
  • Raw logs retained and available, so the numbers can be checked and not merely trusted.
  • A provenance line on every write-up stating exactly how the unit was obtained.

What a vendor receives

  • The results before publication, so any misunderstanding can be corrected while it is still a draft.
  • The raw logs, so your engineers can read the same data I did.
  • Italian-language coverage of the product, which most hardware testing does not provide.
  • No surprises: what is published is what was measured, including the parts that did not go well.
The ask is small.

One unit, about a week on the bench, and return shipping is covered with a prepaid label. A loaner, a returnable demo, or a unit that has already been out and owes you nothing all work equally well. If buying is easier than lending, I would rather buy than ask for something you do not run.
